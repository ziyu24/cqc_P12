# SERVER科学指令

## r001

### 目标

完成一次受限 P0，回答四个问题：相邻实例在受控退化下出现哪些 merge、split、miss 或重复错误；这些错误是否超出尺度匹配的普通单目标漏检；它们是否主要由分数阈值或 NMS 造成；现有公开真实低/高清配对数据是否足以支持下一阶段的真实忠实性检验。不得在本任务中开发新检测器、扩散生成器、超分方法或切片融合方法。

### 假设与判别对象

- H1：在至少一个非饱和退化等级，尺度匹配后相邻组的基数错误增量高于孤立目标 miss 增量，并且至少一种显式非普通 miss 模式（merge、split 或重复）在两个冻结检测器上方向一致，且不能由 NMS/分数阈值解释。
- H0：变化可由目标变小、整体 recall 下降、阈值/NMS 或单一检测器特性解释；此时停止把“相邻实例分解”当作独立科学现象。
- 观察单位是原始图像中的真值实例组，不是每张退化图；所有置信区间按原始图像聚类，不能把同一原图的多个退化版本当独立样本。

### 数据资格门

1. 首先使用 HRSC2016 官方划分，模型训练只读训练集，科学统计只用有公开真值的验证/测试图像。对同类旋转框，以多边形间最短距离除以两目标较短短边得到归一化间距 `g`；`g <= 1.0` 连边后，大小为 2--5 的连通分量作为候选相邻组，最近邻 `g >= 3.0` 的目标作为孤立候选。抽样与任何阈值在查看退化结果前冻结，抽样种子固定为 `20260905`。
2. 自动筛选后，把候选组按固定种子随机排序，依次做清晰参考与标注完整性审计，直到得到 100 个合格组或候选耗尽；保留可确认真实数量、无遮挡到足以判断数量、周边无明显漏标目标的组，记录所有排除原因和比例。若不能得到来自至少 30 幅原图的 100 个合格相邻组，或已审计候选中的明显漏标率超过 5%，HRSC2016 资格门失败。
3. HRSC2016 门失败时才回退 SODA-A 官方划分，沿用同一几何定义与审计协议，并用一句话记录 HRSC2016 不适配原因。SODA-A 中类别、短边像素数和来源图像分层；忽略官方 ignore 实例，不把它们计为背景。
4. 若回退后仍少于 100 个合格相邻组，停止实验路线并报告数据不合格，不用人工合成移动/复制目标补数。

### 冻结观察者与对照

- 使用 ResNet-50-FPN 的标准两阶段旋转检测器 Oriented R-CNN 和标准单阶段旋转检测器 Rotated RetinaNet，采用公开标准训练日程；均只在官方训练划分训练或使用同一官方划分的对应公开权重，验证/测试图像及其退化版本不得参与训练或调参。
- 每个观察者先复现其原始清晰验证集的公开配置指标；与所用公开配置报告值相差超过 2.0 AP 时，先修复复现问题，不进入科学比较。之后冻结权重、预处理和所有非明确扫描参数。
- 主要分析的分数阈值固定为 `0.25`；敏感性分析统一使用 `0.05/0.25/0.50`。主要旋转 NMS 参数采用对应公开配置默认值，敏感性分析统一扫描 `0.1/0.3/0.5` IoU 阈值，并保存 NMS 前候选以区分网络错误与后处理错误；不得为不同退化等级分别调阈值。
- 主要转变队列只包含清晰图上被两个检测器都完整分解的合格相邻组；若该共同队列少于来自 20 幅原图的 50 组，则停止跨检测器主张。完整合格集上的无条件结果同时报告，防止清晰图筛选掩盖失败。
- 对每个大小为 `k` 的相邻组，从孤立候选中选取 `k` 个目标组成匹配伪组，按数据集类别、清晰图短边像素数、局部对比度和清晰图置信度匹配。局部对比度固定为目标 OBB 内灰度中位数与 `1.5` 倍 OBB 外环灰度中位数之差的绝对值除以 `255`。孤立目标也必须在清晰图上被两个检测器正确检测；无法达到共同支持的样本不外推。

### 受控退化

- 只做确定性的整图退化，保持画布、目标位置和真值框不变。四级严重度为：原图；高斯 PSF `sigma=0.8` 后 2 倍面积下采样；`sigma=1.6` 后 4 倍面积下采样；`sigma=3.2` 后 8 倍面积下采样。所有非原图均用双三次插值恢复到原画布再送入检测器。
- 本轮不加入噪声、JPEG、空间变化退化或学习式退化，避免多因素混杂；不把这些等级解释为任何具体传感器或 GSD。
- 对每个实例记录退化后的有效短边像素数，并按归一化间距、有效短边、局部对比度和严重度分层。

### 错误定义与指标

- `resolved`：组内每个真值都能以 OBB IoU `>=0.5` 一对一匹配到不同预测，且无多余组内预测。
- `merge`：同一个预测分别覆盖至少两个真值各自面积的 `>=50%`；只有预测数减少而不满足此几何条件时不得记为 merge。
- `split/duplicate`：同一个真值对应至少两个分数合格预测，且每个预测与该真值 OBB IoU `>=0.3`；分别报告 NMS 前后结果。
- `miss`：真值没有 OBB IoU `>=0.5` 的一对一匹配，且没有被已确认 merge 预测覆盖。错误可多标签并存，必须同时报告联合事件，不强行互斥。
- 主要指标为完整分解率、基数错误率、merge/split/miss 率及其严重度转变曲线；常规 AP、recall、SSIM/LPIPS 只作上下文，不能替代组级指标。
- 主要效应为相对清晰图的“相邻组未完整分解率增量减去同大小匹配孤立伪组未完整检出率增量”；两者都以组为单位，避免把组错误率与单目标 miss 率直接相减。报告绝对百分点差、按原图聚类的 95% bootstrap 置信区间和两个检测器的分别结果；同时给出 merge、split/duplicate、miss 的事件级增量。

### 真实观测资格审计

只审计 DSR 与 RRSISR 的官方论文、元数据、划分和少量样本，不先下载或标注整个数据集。逐项检查：是否为同一静态场景的真实低/高清观测、目标布局是否不变、是否有可独立确认的高清数量真值、是否含足量相邻目标、配准误差能否低于目标短边的 0.25、相机/焦距/高度/处理差异是否可追溯。下一阶段最低资格为不少于 10 个独立场景和 50 个合格相邻组；输出 `qualified`、`conditionally_qualified` 或 `unqualified`，未知项不得推定通过。

### 继续与停止条件

- 只有在两个检测器上，相邻组相对孤立对照的主要效应都至少为 10 个百分点且 95% 置信区间下界大于 0，并且至少一种 merge/split/重复事件增加至少 5 个百分点（一个检测器下界大于 0、另一个方向一致），且结论通过分数阈值和 NMS 敏感性分析，才建议继续相邻实例主线。
- 若效应只在最严重、整体检测已接近失效的等级出现，不算通过；至少要在孤立目标仍有 50% 以上 recall 的等级成立。
- 若结果主要是尺度匹配后同步的普通 miss、只由 NMS 产生、只在单一检测器出现、标签资格门失败，或效应未达到上述门槛，停止该路线并如实记录负结果。
- 即使受控合成 P0 通过，只要真实观测资格不是 `qualified`，也不得开发或宣称 real-world-faithful 退化模型；下一步只能补充真实数据证据或关闭顶刊主张。

### 所需科学输出

- 数据资格与样本流表：候选数、审计数、排除原因、最终相邻组与孤立对照数。
- 两个检测器的清晰基线复现证据、完整配置身份和冻结阈值。
- 按严重度、间距、有效短边和检测器分层的 error taxonomy 表与转变曲线；至少给出主要效应、置信区间和 NMS 前后对照。
- 可复核的 merge/split/miss 示例索引和盲于结论的随机审计样本，不只展示最好看的案例。
- DSR/RRSISR 资格表，明确事实、未知、配准与目标数量证据。
- 唯一结论：`continue` 或 `stop`，逐条对应门槛；没有真实配对证据时明确标记 `synthetic-controlled only`。
- 任务结束后把充分统计、代码与配置身份、结论、适用范围和可执行重建方式写入 `lab/result.md`；触发停止时把主要失败及边界同时写入 `lab/failed_methods.md`，再清空本任务槽。
