# SERVER 科学指令

## r005

### 唯一目标与假设

停止已经被 r004 否决投入的“邻接特异失效→任务忠实生成器”路线，独立验证一种最小检测方法：**训练时让证据支持随已知退化扩展，预测时仍定位原物体的紧致 OBB，能否比强退化增强和已有标签分配更少漏检且不损伤定位。**本任务不优化最终 NMS、不开发生成器，也不以相邻组必须更差为前提。

主假设是：退化条件证据分配相对最强非本方法对照，提高固定退化组上的原始 OBB AP75 和 AR100，同时保持清晰图 AP75；方法只改变训练监督，推理网络、参数量和输出定义不变。若收益只来自扩大评价框、增加推理分支或改变原始 OBB 真值，假设不成立。

采用已登记且在 HRSC2016 和 DOTA-v1.0 都有 valid 基线的 Rotated RTMDet-R-S，继承其模型与优化语义。HRSC 登记条目的评测阈值文字存在矛盾，先以实际配置与日志核清，只把 checkpoint 用于确认来源和必要的实现预检，不把登记数当作本任务结果；正式比较的所有臂使用相同公开初始化，在本任务的同一数据、增强、全局 batch、优化步数和选优规则下重新训练。

### 数据、划分与退化

1. 首验使用 HRSC2016。开发只使用官方 train 与 val 身份；test 不参与方法、强度或选优规则的选择。若现有发布没有独立 val 身份，从 trainval 按原图一次性确定训练/开发划分并在看任何方法结果前冻结。方法冻结后，以 trainval 重训并在 test 做一次三种子报告。由于本项目已经多次查看 HRSC test，它是实现和内部复核证据，不称为独立确认。
2. 训练增强保持 25% clear；其余样本独立采样居中高斯模糊强度和面积下采样倍数，再恢复原画布。所有比较臂按图像身份、训练步和种子共享同一退化抽样。退化只改图像与本方法的证据元数据，不改原始 OBB。
3. 固定评价网格为 sigma∈{0,0.8,1.6,3.2} 与面积下采样倍数∈{1,2,4,8} 的完整 4×4 组合；clear 是 0/1，其余 15 格为退化主集合。分别报告纯模糊、纯采样、组合退化和严重度趋势，不能只报告当前旧实验的三条对角组合。
4. HRSC 开发通过后，原封不动地将方法、超参数、训练比例、评价网格和裁决规则迁移到 DOTA-v1.0 train→val；不依据 DOTA 结果改结构或重新选超参数。切片、尺度和增强派生自同一原图的样本必须留在同一数据分区，统计也按原图聚类。

### 必须同预算比较的实验臂

- `B0`：原始 clear 训练，用于量化强退化增强的收益和清晰上限。
- `B1`：原始 OBB 加上述强退化增强，保持检测器原生分配；这是最低有效基线。
- `B2`：在 B1 上实现 RFLA 的高斯感受野距离与分层标签分配，按论文定义适配旋转框；不能用普通中心采样冒充。
- `B3`：在 B1 上实现 CVPR 2021 模糊框扩张的旋转框适配。它按有效核支持扩张训练框；同时给出论文式扩张框评价和本任务的原始 OBB 评价，裁决只使用后者。
- `M0`：固定证据扩张，扩张量等于训练退化分布的平均值，回归仍用原始 OBB；用于排除“只要增加正样本即可”。
- `M1`：完整退化条件证据分配。由每次实际退化的有效点扩散协方差与 RFLA 的原 OBB/感受野表示形成证据分布，以感受野距离选择候选；一个候选位置对所有 GT 的责任归一化，只归属最大责任实例，重叠且责任接近的位置按退化强度降权；所有正位置的回归目标始终是原始 OBB。退化为零时新增协方差和归属降权都严格为零，分配退化为 B2。

`M1` 只允许开发两个科学超参数：退化协方差缩放系数从 {0.5,1,2} 选择，归属不确定降权阈值从 {0,0.1,0.2} 选择。先固定前者再固定后者，不做连续搜索，也不同时改变损失、骨干、neck 或推理后处理。另做 `M1` 去掉退化条件、去掉归属竞争和把回归改成扩张框的三项消融，以辨认真正有效成分。

### 实现必须满足的可执行反例

在开始正式训练前，用实际生产分配函数证明：零退化时退化协方差和新增降权为零，M1 与 B2 数值一致；同一候选最多归属一个 GT；重叠责任和为一且近似并列时权重下降；改变证据支持不会改变任何回归真值；旋转、缩放、裁切和翻转后有效核协方差与 OBB 坐标处于同一坐标系；固定增强种子时所有实验臂接收逐图相同输入。工程问题须修复后继续，不能以反例检查代替最低成本性能信号。

### 分阶段性能信号与统计

1. **HRSC 开发筛选。** 固定开发种子为 5，先完成 B0、B1、B2、B3、M0、M1 和三项 M1 消融；B0 必须按本任务协议训练，不能复用不同训练协议的旧权重。只按 val 的 15 格退化平均 AP75 选择唯一 M1 设置。若 M1 相对 B1/B2/B3 中最强者的退化平均 AP75 不提高至少 2.0pp，或 AR100 不提高至少 1.0pp，或 clear AP75 下降超过 1.0pp，立即完成负结果并停止，不运行 DOTA。
2. **HRSC 稳定性报告。** 开发门通过后，固定所有选择，以种子 {17,29,43} 完成 trainval→test。报告每种子与均值；每次 bootstrap 对全部实验臂和种子共享同一原图重采样，逐种子重算 AP 差后再取三种子均值，区间表示测试图像抽样不确定性，种子间标准差另报。所有 15 格复用同一批抽样索引。HRSC 结果只检查实现稳定性，不重新选方法。
3. **DOTA 独立确认。** 只有 HRSC 门通过才运行 B1、B2、B3 和 M1 的三个同种子训练。主要终点为 15 格退化平均原始 OBB mAP75；次要终点为 mAP50、AR100、clear mAP50/mAP75、按类别和按目标尺度结果。每次 bootstrap 以原始大图为簇，对全部臂和种子共享抽样，逐种子重算 AP 差后取三种子均值；区间与种子间标准差分开报告，不能把切片当独立样本。
4. AP 与 AR 均用同一预测上限和固定后处理，原始 OBB 是唯一主真值。另报匹配真阳性的 IoU 分布、在固定每图假阳性数下的 recall，以及邻接距离分层结果；后者只作机制诊断，不恢复邻接特异主张。报告训练成本、参数量、FLOPs 和同设置推理时延；训练期专用分配应使推理参数量和 FLOPs 与 B1 相同。

### 唯一裁决

- `continue`：HRSC 开发门通过，并且 DOTA 上 M1 相对 B1/B2/B3 中最强者的退化平均 mAP75 提高至少 1.0pp、配对 95% 区间下界大于 0，三个种子点估计同向；AR100 同向，clear mAP75 下降不超过 0.5pp，且收益至少在纯模糊、纯采样、组合退化中的两类出现。此时只获得继续建设 TGRS 方法论文的资格，真实低质量影像验证仍是下一项未知证据。
- `stop`：HRSC 未过开发门；或 HRSC 通过但 DOTA 未过上述门；或仅扩张框评价、单个饱和格、单种子、放宽真值、额外推理计算才能获益。此时停止该方法候选，不换名称重复训练。
- `inconclusive`：只有数据身份或必要真值客观不可获得，导致主要终点无法定义时使用。一般实现、兼容、资源或单次执行错误须在同一任务内修复并继续。

### 完成时交付

交付冻结的数据身份、退化定义、全部训练臂实际配置、实现反例、逐种子 checkpoint 选优依据、16 格完整指标、原图簇配对区间、效率、预先固定样例上的证据权重与紧致 OBB 可视化，以及 `continue`/`stop`/`inconclusive` 的唯一结论。报告必须明确区分事实、推断和未知；失败路线按项目规则归档，不能只留下最佳数字。
