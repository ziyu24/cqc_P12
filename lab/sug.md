# SERVER科学指令

## r002

### 目标

不改变 r001 的数据、四级退化、两类检测器、指标或成败门槛，只修复证据生成链后复算一次，给出可接受的 `continue`、`stop` 或 `inconclusive`。不开发新模型，不增加数据集，不扫描新退化参数；现有 DSR/RRSISR `unqualified` 结论没有新一手样本证据时不重复调研。

### 待纠正的五项偏差

1. 主要效应必须只在清晰图上被两个观察者都完整分解的共同队列计算；完整合格集只作无条件补充。共同队列仍须不少于 50 组且覆盖至少 20 幅原图。
2. 每个相邻组成员分别匹配唯一孤立目标，协变量固定为对数短边、既定局部对比度、Oriented R-CNN 清晰置信度和 Rotated RetinaNet 清晰置信度。采用不放回的全局最小总距离匹配；控制图像不得与相邻组图像重合，控制目标和控制图像不得跨伪组复用。四项协变量匹配后的绝对标准化均差均须不超过 0.1，否则缩小到共同支持集；缩小后低于样本门则判 `inconclusive`，不得外推。
3. 真值—预测的一对一匹配必须使用 IoU `>=0.5` 图上的最大基数二分图匹配，并在最大基数解中最大化总 IoU；不得使用按 IoU 排序的贪心替代。
4. 必须保存解码、分数过滤之后且旋转 NMS 与 `max_per_img` 之前的候选；所有 NMS 阈值从同一批冻结候选离线生成。NMS 前和 NMS 后分别计算 resolved、merge、split/duplicate、miss，不能用 NMS=1.0 冒充 NMS 前结果。
5. 置信区间必须覆盖相邻图像和所有控制图像的依赖。以共享任一原始图像为边形成依赖连通分量，按连通分量进行 4,000 次 bootstrap；不得只用相邻图像编号聚类。

### 观察者资格与数据泄漏修正

- 不再使用 test 表现选择 best epoch。优先评估 r001 已产生的固定最终 epoch：Oriented R-CNN 第 36 epoch、Rotated RetinaNet 第 72 epoch；若产物不存在，按原固定训练日程重建，但训练期间不得读取 test 指标。模型一经按 epoch 固定，不因 test 结果更换。
- 使用与官方一致的 AP50 定义复核清晰基线：Oriented R-CNN 的既定参考为 90.36，Rotated RetinaNet 官方同配置参考为 84.80。任一观察者相差超过 2.0 AP 时，必须先定位配置/数据适配问题或改用对应官方权重；不能以不合格观察者继续生成科学结论。若无法得到两个合格观察者，本任务结论为 `inconclusive` 而非科学 `stop`。
- 沿用 r001 固定的 100 个已审计相邻组，但补充逐候选的接纳记录；不能只保存“100/100”总数。任何接纳记录无法复核时重新盲于退化结果审计该候选。

### 必须先通过的回归反例

- 构造两真值、两预测的交叉边反例：贪心只能匹配 1 对时，最大基数实现必须返回 2 对。
- 构造一组属于共同清晰队列、一组不属于的汇总反例：改变后者不得改变主要效应或其置信区间。
- 构造相邻图像相同或控制图像共享的反例：依赖图必须把相关记录放入同一 bootstrap 分量；主分析数据中控制图像复用必须被拒绝。
- 对同一冻结候选分别执行三个 NMS 阈值；输入候选标识必须完全相同，NMS 前事件统计也必须完全相同。
- 构造协变量失衡样本；任一绝对标准化均差超过 0.1 时资格门必须失败。

### 统计与裁决

- 保持 r001 主分数阈值 0.25、敏感性分数 0.05/0.25/0.50、NMS 0.1/0.3/0.5、相同四级退化和原错误定义。
- 主要效应仍为相对 clear 的“共同队列相邻组未完整分解率增量减去匹配孤立伪组未完整检出率增量”；同时报告 merge、split/duplicate、miss 的事件级增量、95% 置信区间和非饱和等级结果。
- 继续门完全沿用 r001：两个合格观察者的主要效应均至少 10pp 且置信区间下界大于 0；至少一种非普通 miss 事件增加至少 5pp，且一个观察者下界大于 0、另一个方向一致；还须通过分数和 NMS 敏感性，且在孤立目标 recall 仍高于 50% 的非饱和等级成立。
- 完整纠偏证据通过而继续门失败，结论为 `stop`，再把失败边界写回 `lab/failed_methods.md`。任一证据资格门、观察者复现门或所需产物缺失，结论为 `inconclusive`，不得登记科学失败。只有完整纠偏证据通过且继续门通过才给 `continue`。

### 所需科学输出

- 五个回归反例的通过记录；共同队列、完整合格集和匹配后共同支持集的样本流。
- 两个固定观察者的 checkpoint 选择规则、AP50 复现差、训练/评估隔离证据。
- 四项匹配协变量的匹配前后标准化均差、控制复用检查和依赖连通分量统计。
- 同一冻结候选上的真正 NMS 前结果及三个 NMS 后结果；最大基数匹配的逐组事件明细。
- 纠偏后的主效应、事件级增量、置信区间、分数/NMS 敏感性和唯一科学裁决，并明确它与 r001 原始数字是否一致。
- 结果与关键可重建产物必须具有可校验的 provenance；结束后把 r002 充分统计写入 `lab/result.md`，按裁决更新 `lab/failed_methods.md`，再清空任务槽并提交、推送。
