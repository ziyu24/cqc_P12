# SERVER 科学指令

## r004

### 目标与已有证据

完成正确冻结观察者条件下的相邻实例退化对照实验，给出是否值得继续顶刊路线的唯一科学裁决。继承 HRSC2016 的既有候选名单、两份权重、四级退化及原继续条件。本任务只补齐原科学问题的有效证据，不重训检测器，不扩数据，不开发生成器。

已验证的官方 VOC07 AP50 为 ORCNN 90.3558%、RetinaNet 84.7564%，与各自参考一致，直接继承。原 100 个候选组中共同 clear 可完整分解的是 74 组、63 幅相邻原图；这是匹配和共同支持筛选之前的数量，不能直接作为最终分母。原异常 AP、27 组队列和错误 RetinaNet 的退化效应均不能用于本次裁决。

### 先固定清晰样本和对照

1. 沿用原 100 个候选组的身份与顺序，逐组引用真实存在的接纳依据。程序统一生成的 accepted/盲审说明不等于人工审阅证据；缺依据者仅看 clear 影像和标注补核，记录实际执行方式与排除理由，不能声称机器检查是人工盲审，也不依据退化结果挑样本或补入新组。只因模型未检出不能认定标注错误。
2. 保持已经恢复的 RetinaNet 旧版锚框语义：锚框角度参数为 Python None，框解码器仍为 le90；权重、预处理和其余科学配置不变。标准 clear 预测可继承；清晰置信度匹配需要正确观察者的真正最终 NMS 前候选，不能用错误候选或只用标准推理的截断输出代替。
3. 排除全部相邻源图后，从已有孤立目标池进行逐成员、不放回全局匹配。四协变量为 log(短边)、扣除目标内部后的局部背景对比度、两个观察者各自的 clear 置信度。目标和控制源图都不能跨伪组复用，每个伪组成员数与对应相邻组一致。
4. 用正确 RetinaNet clear 置信度重新确定控制，不能沿用旧控制选择。主队列要求两个观察者在 clear、score=0.25/NMS=0.1 都完整分解；控制伪组的 clear 表现如实保留，由配对差扣除，不另挑控制端表现最好的组。匹配/共同支持规则只能依据 clear 信息，并在计算本次退化效应前固定；必要时整组排除，保留排除原因。
5. 报告候选→有效接纳→共同 clear→匹配共同支持的样本流，以及匹配前、全部匹配后、最终主队列内的四项绝对 SMD。最终主队列须至少 50 组、20 幅相邻原图，四项 SMD 均≤0.1；全体平衡不能代替主队列平衡。不得通过查看退化效应反复改变匹配规则。最终名单、控制对应关系和 clear 基线确定后，所有等级与敏感性均使用这份队列。

### 最低成本推理顺序

- 沿用 clear 与三档整图退化：高斯 sigma/面积下采样倍数分别为 0.8/2、1.6/4、3.2/8；线性缩放为面积倍数的负二分之一次方，先高斯模糊、INTER_AREA 缩小，再 INTER_CUBIC 回原尺寸，继承原边界与取整实现。
- 正确 RetinaNet 重新生成所需 clear 和三档退化候选。ORCNN 只复用配置、输入和数值语义一致的既有候选；重新匹配可能选中新控制图，逐图逐等级核对覆盖并补算缺项，禁止悄悄丢弃没有缓存的控制或将其换回旧控制。缓存不确定时只重算受影响输入。
- 先产出固定主队列的 clear/最严重等级结果，包含双观察者的相邻与控制原始率、额外风险、事件和孤立 recall；这是早期性能信号，不是提前停止点。随后完成两个中间等级。最严重等级若孤立 recall≤50%，仍用中间等级寻找非饱和区，不能据饱和结果裁决路线。
- 主设定 score=0.25、NMS=0.1；随后从同一份候选完成 score∈{0.05,0.25,0.50}、NMS∈{0.1,0.3,0.5} 的完整组合。四级、双观察者、九种后处理共 72 个条件，全部报告估计与区间。敏感性各自减去对应后处理的 clear 基线，不重新挑选共同 clear 赢家。
- 最终 NMS 前候选分数下限为 0.05，分别保留 ORCNN 与 RetinaNet 原生坐标恢复及有效框语义。清晰 AP 已完成，不重复全量 AP 或已解决的环境诊断；必要的候选回放只检查受改变的生产分支和非单位缩放情形。

### 估计量、事件与归因

对每组 g、观察者 d、等级 l 和后处理 h，计算

`D(g,d,l,h) = [U_adj(l,h) - U_adj(clear,h)] - [U_ctrl(l,h) - U_ctrl(clear,h)]`，

其中 U_adj 表示相邻组未完整分解，U_ctrl 表示同大小孤立伪组未全部完整检出。主效应是最终固定队列中 D 的按组平均，单位 pp；不同成员数的组仍各占一个组的权重。目标级孤立 recall 则按匹配目标总数/控制 GT 总数计算，并另报按组平均版本，避免混用分母。

- 用 IoU≥0.5 的最大基数一对一匹配，再最大化总 IoU。完整分解要求全部 GT 匹配且相关预测数与 GT 数一致。保持既有相关预测 IoU≥0.3 的口径。
- merge：一个预测覆盖至少两个 GT 各自面积的 50%；duplicate：一个 GT 对应至少两个 IoU≥0.3 的预测；miss：未匹配且不属于 merge 覆盖的 GT。事件可以重叠，须保留明细；duplicate 不称为已证实的语义 split，少一个预测也不自动称为 merge。
- 报告相邻组 merge/duplicate/miss 相对 clear 的增量、基数错误率和相关预测数与 GT 数之差。控制端对应事件与相邻减控制的事件增量一并列出。merge/duplicate 才可支持非普通 miss 的事件条件；仅基数错误增加不能排除普通漏检解释。
- 每个后处理分数下，分别给出最终 NMS 前、NMS 后截断前、最终输出的最大匹配数/GT 数，区分 NMS 覆盖损失和输出数量截断损失。允许原始重复候选存在；不能要求 NMS 前 resolved 才承认有匹配覆盖。原生候选预筛选和 ORCNN 的 RPN 限制须注明，此归因不等于物理分辨极限。
- 以共享任一相邻/控制原图建立组级依赖图；一个组节点携带全部观察者、等级、后处理记录。按连通分量进行 4,000 次配对 bootstrap，抽中分量时带入全部组，按组总数计算效应；所有条件复用同一批抽样索引。报告真实组数、原图数、分量数及每分量组数，不能把 72 条重复测量当作 72 个独立组。目标级指标在每次抽样内重算其分子/分母。
- 报告逐条件 95% 区间与完整合格集的无条件补充；区间是条件估计的点态区间，不能解释成跨等级/事件搜索校正后的显著性。任何 NaN/空队列都显式标注原因，不转换为零效应。

### 只修复会影响这些输出的生产缺陷

落实本次配置的候选上限、缓存复用和分析字段，候选上限不能当作实际接纳数。旧实现仍缺最终主队列平衡、全部敏感性区间和覆盖归因，不能仅换配置重跑后就声称完成新协议。

保留并执行实际生产函数上的反例：交叉边匹配须为两对；加入不合格组不能改变主结果；共享控制图会合并依赖分量且主匹配拒绝复用；四级记录中 clear 正确、退化仅相邻侧失败时主效应为 100pp；大小不同分量仍按组加权；短边/背景环与最终队列失衡能被真实检查识别；同一候选在各后处理间不变且坐标回放正确。验证与核心输出同步完成，不能停在自测 True 或用其他诊断替代性能结果。

### 唯一裁决与后续投入

原继续条件不变：在同一退化等级、两观察者各自的孤立 recall 都>50% 时，两观察者主效应均≥10pp 且 95% CI 下界>0；至少同一种 merge 或 duplicate 增量≥5pp，其中一个观察者 CI 下界>0，另一个方向一致；完整分数/NMS 表支持该现象。不得仅挑一个有利阈值，或要求所有敏感性格都显著来替代原条件。若效应随 NMS 放宽消失且候选覆盖恢复，明确记录后处理依赖，不升级为稳定的实例分解机制。

- continue：有效证据满足原条件，值得准备独立密集数据、模糊与采样分离及真实配对资格验证；本任务到此完成，不自动启动这些后续实验。只取得研究继续资格，不等于已有顶刊贡献。
- stop：有效证据不满足原条件，停止当前“实例分解特异性→任务忠实退化”投入路线；同时说明区间是否仍容许有意义效应，不能以不显著声称零效应成立。
- inconclusive：有效接纳/共同支持不足或必要科学证据仍不可获得，如实给出具体缺口。一般代码、兼容或计算错误须修复并继续，不能用工程退出代替这个裁决。

### 完成时必须交付

一份可重算的结果摘要和逐组证据，至少包括：继承的官方 AP 与观察者身份；真实接纳依据和完整样本流；最终控制映射、四协变量平衡、依赖簇；首个性能信号；72 个条件的原始率、主效应、事件、孤立 recall 与 95% CI；候选标识及 NMS/截断覆盖损失；生产反例的实际结果；完整合格集补充；唯一裁决及与旧有偏结果的区别。负结果和不确定结果也交付完整表，最后明确顶刊路线的下一项必要证据。
