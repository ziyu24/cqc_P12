# 科学讨论

## 研究范围与证据锁（2026-09-05）

### 当前主问题

唯一主线是：研究相邻遥感目标在成像退化下何时从可区分变成不可区分，以及冻结检测器随之出现的 merge、split、miss 和重复检测错误。退化生成当前只是制造受控观测条件的工具；不同时开发新检测器、扩散生成器或切片融合方法。

论文级候选假设是：即使一般图像质量和单目标检测表现相近，普通退化模拟仍可能错误预测相邻目标组的实例基数与错误类型；只有该缺口在合格真实观测、未参与校准的场景和检测器上成立，才值得研究受约束的任务忠实退化模型。这是待验证假设，不是项目已有结论。

### 已确认事实

- 当前基线为远端 `ziyu24/cqc_P12` 的 `main` 提交 `012f449b1733773b3039f8abe043ed9087a9a70e`；此前只有初始化内容，没有代码、实验或项目结果。
- `ziyu24/cqc_research_lessons` 当前 `main` 没有 `lesson/cqc_P12.lessons.md`。这只表示尚无已登记教训。
- HRSC2016 提供舰船的水平框和旋转框，规模较小，适合低成本首验；但[已有重标注研究](https://doi.org/10.3390/rs14215460)报告原标注存在小船漏标，因此必须先做相邻组标注资格审计，不能直接把预测数少于真值数解释为不可分辨。
- SODA-A 官方资料报告 2513 幅航空影像、872069 个九类旋转框实例，密度远高于 HRSC2016，可在 HRSC2016 不合格时作为回退；它仍是已经成像和处理后的公开影像，不是真实退化过程的原始场景真值。
- DSR 提供同场景、不同焦距的低/高清对及十个飞行高度，但是否含足量静态相邻目标及可用目标真值尚未确认。RRSISR 提供经配准的真实低/高清遥感图像对，但相邻目标数量、标注与配准精度对本任务是否合格也尚未确认。

### 最近邻限制

- [BSRGAN](https://arxiv.org/abs/2103.14006) 已系统组合模糊、下采样、噪声、JPEG 与相机噪声；仅增加退化种类不构成创新。
- [Meta-Sim](https://openaccess.thecvf.com/content_ICCV_2019/html/Kar_Meta-Sim_Learning_to_Generate_Synthetic_Datasets_ICCV_2019_paper.html) 已用真实数据分布和下游任务目标优化合成数据生成器；仅加入检测反馈不构成创新。
- [SDQM](https://doi.org/10.1117/1.JEI.35.3.033014) 已面向目标检测评价合成数据质量；仅用检测性能评价生成数据不构成创新。
- [DFF](https://arxiv.org/abs/2512.16468) 已比较真实/合成图像下系统决策证据并据此校准模拟器；宽泛的“行为忠实性加模拟器校准”不是空白。
- 2026 年已有工作直接[模拟多级遥感图像退化并测量 YOLO 检测变化](https://doi.org/10.1117/12.3094817)；只画“质量下降—mAP 下降”曲线不够。
- [DSR](https://github.com/IVRL/DSR) 与 [RRSISR](https://doi.org/10.1109/TGRS.2024.3516538) 证明真实配对遥感退化数据并非完全不存在，但它们对相邻实例分解任务的资格仍需样本级审计。

### 首轮方案裁决

考虑过三条路线：直接开发复杂退化生成器、先建设真实配对数据集、先做受控合成 P0。前两条在核心现象和数据资格都未成立时成本过高；采用受控 P0，先判定相邻实例错误是否是独立于普通小目标漏检和 NMS 的稳定现象，同时只做真实数据资格审计。

按照项目首次验证规则，先使用 HRSC2016；若相邻组数量、清晰参考可辨认性或标注完整性门失败，再回退到 SODA-A，并在同一任务中如实记录原因。

### 必须保持的解释边界

- “两个真值目标只得到一个预测”不自动等于 merge；只有单个预测在几何上同时覆盖至少两个真值时才记 merge，其余按匹配结果记 miss、split 或其他错误。
- 可分辨性不是纯图像属性。首轮测量的是给定数据、退化协议和冻结观察者下的条件行为；跨两个检测器一致只能降低模型特异性风险，不能证明物理极限。
- 数字退化结果只能支持 synthetic-controlled 结论。没有同景真实观测和独立真值，不使用 `real-world-faithful`、物理不可分辨边界或传感器性能保证等表述。
- 只有相邻组效应在尺度匹配的孤立目标对照、分数阈值/NMS 扰动和第二检测器下仍存在，且包含稳定的非普通 miss 错误，才继续该科学问题。
- 只有真实配对数据资格门通过，才允许下一阶段比较“图像质量匹配、单目标行为匹配、相邻组行为匹配”或开发受约束校准方法。

## r001 服务器证据复核（2026-09-05）

### 已确认

- 服务器完成了 HRSC2016 的候选组筛选、两种检测器训练、四级受控退化推理、分数/NMS 扫描和 DSR/RRSISR 公开资料审计，并把代码、配置和摘要提交到远端 `main`。

- 当前公开 MMRotate 的 Rotated RetinaNet R50-FPN 6x HRSC 参考为 AP50 84.80；服务器选择的 epoch 64 报告 77.75。二者训练集并不相同：公开配置使用 `trainval.txt`，r001 使用 `train.txt`，所以 7.05 AP 差不能单独判为实现复现失败。
- MMRotate 的官方 HRSC 配置明确使用 `trainval.txt` 训练、`test.txt` 同时作为 `val_dataloader` 和 `test_dataloader`。因此 `val_dataloader` 是框架评估角色，不表示底层文件是独立 validation split；r001 实际是 `train.txt -> test.txt`，不是 `train -> val`。
- 主机 `pth_data/readme.md` 的对应索引已有可直接复用的 HRSC2016 Oriented R-CNN R50-FPN 3x 权重：`baseline_oriented_rcnn_r50_fpn_3x_le90/HRSC_trainval_test/best_dota_mAP_epoch_34.pth`，AP50 为 0.9036、状态 valid、可直接 inference。当前 74 项索引没有 HRSC2016 Rotated RetinaNet 条目；第二观察者可使用 MMRotate 官方发布的 6x HRSC 权重，兼容性失败时才按官方 `trainval -> test` 配方重建。

### 改变裁决的协议偏差

1. 汇总器只报告共同清晰队列的数量，没有用该队列筛选主要效应；可复现合成探针显示，共同队列只有 1 组时，加入 1 个不合格组会把应为 100pp 的主要效应错误报告为 50pp。
2. 孤立伪组只按相邻组最小短边匹配，没有执行预注册的逐目标短边、局部对比度和两检测器清晰置信度匹配；bootstrap 又把控制图像的变化挂到相邻图像簇，未按所有原始图像依赖聚类。
3. 推理脚本读取的是框架已经完成 NMS 后的 `pred_instances`；NMS=1.0 只是近似少抑制，不是真正的 NMS 前候选，不能完成原定的网络/后处理归因。
4. 一对一匹配采用按 IoU 排序的贪心算法，却被注释为最大基数匹配。存在两真值、两预测的简单反例，贪心只得到 1 对而最大基数解为 2 对，会直接改变 resolved/miss 事件。

### 对数据划分裁决的修正

- 撤回“使用 best checkpoint 本身足以使 r001 无效”的过重裁决。HRSC 模型库通常按 `trainval -> test` 报告 best；在本受控 P0 中，检测器只是冻结观察者，只要在退化分析前固定、且不按退化效应挑选 checkpoint，就可使用归档或官方 best。
- r001 的 `train.txt -> test.txt` 仍须如实记录，但不再把它作为独立硬阻断。需要修正的是观察者与其参考训练集不一致：优先复用 `pth_data`/官方 `trainval -> test` 权重，而不是用 test 上的 final epoch 替代 best。
- `splits/test.txt` 可继续作为本轮受控退化和统计样本；本轮不把该结果表述为独立外部泛化。若后续开发或选择退化模型，必须另留未参与选择的数据。

### 当前裁决

r001 的服务器执行记录保留，但其科学状态仍为 `inconclusive / protocol_drift`。这项裁决现在只由会改变主要效应或事件归因的四类问题支撑：共同队列未实际筛选、控制匹配与依赖聚类不合规、没有真正 NMS 前候选、贪心匹配不等于最大基数匹配。下一步只做一次低成本纠偏复算：优先复用 `pth_data` 或官方权重，不改变数据、退化和原始门槛；若修正后仍失败，才确认 stop。

- **权重兼容可恢复，已经实测。** 对 checkpoint 的 NumPy metadata 使用局部 Unpickler，只把 `numpy._core.multiarray` 的 `_reconstruct`/`scalar` 映射到当前 `numpy.core.multiarray` 对象；没有全局 `sys.modules` 别名。348 个 state-dict 值均为有限张量，向归档配置创建的 Oriented R-CNN 执行 `strict=True` 加载，全部键匹配。权重 SHA-256 为 `9a22a0d164b20c054d0ab91f06c12ce88eb3f3611430ffb2653dc05b7fc1412c`。这只证明反序列化与参数结构兼容，**没有执行前向或测量 clear AP50**，不能直接认定观察者已完整复现。适配器是兼容代码，不是安全受限的反序列化器，仅用于可信归档权重。
- **生产汇总器有确定性错误，已经实测。** 构造一组 clear 正确、退化后只在相邻侧漏检的完整四级记录，真实应得效应 100pp；实际 `summary()` 得到 NaN，依赖图明明有 1 个分量，汇总却报告 0 个。原因是 `dependency_components()` 返回整数行索引，而汇总字典以字符串 `record_key` 索引。修正后还要保持“按组平均”的估计量：抽到一个依赖分量时携带其全部组，按组数计算分子/分母，不能把大小不同分量的均值等权平均。
- **NMS 前接口不兼容，已经核实安装代码。** 归档 ORCNN 使用的 `mmdet.Shared2FCBBoxHead` 没有 `_bbox_post_process`，现有统一 hook 会出错；RetinaNet 的该函数同时负责把框缩放回原图，直接替换为 identity 会跳过坐标恢复。两类观察者必须分别提取候选，并验证离线 NMS 能复现标准推理。ORCNN 最终 RoI NMS 前候选仍在 RPN 筛选之后，不能据此声称检查了全部网络前端信息。
- **控制样本总容量足够，共同支持仍未知。** 100 组/86 幅相邻图包含 240 个目标；排除相邻源图后有 356 个孤立目标，来自 271 幅源图。271≥240 说明“一幅控制图最多一个控制目标”的匹配在总容量上可行，不保证四协变量平衡或最终共同队列合格。
- **静态代码复核还发现两处协变量偏差。** 实现使用 `log(sqrt(area))`，协议要求 `log(short_side)`；局部背景环只填外边界，未扣除环孔，实际混入目标内部。恢复既定短边和背景环语义，并报告在最终主队列内的平衡情况。原自测的共同队列与同一 NMS 候选两项分别只是均值恒等式、集合恒等式，没有调用实际队列筛选或候选流水线；五个 True 不能作为整条证据链已通过的证据。

以遥感方法顶刊为目标时，TGRS 比立即承诺 TPAMI 更合理；若真实跨成像条件证据和应用意义充分，再评估 ISPRS Journal of Photogrammetry and Remote Sensing。期刊定位是当前研究判断，不是录用概率。TGRS 官方明确要求方法进展、重要研究及完整实验条件，现有工程诊断尚不满足这一要求：[TGRS 范围](https://www.grss-ieee.org/publications/transactions-on-geoscience-remote-sensing/)。

未检索到完全等同题目不能证明新颖性。当前最值得保留的论文问题是：**在单目标表现相近时，目标间隙相对于有效模糊宽度的变化，是否产生可预测、跨观察者的实例分解额外风险；普通模拟能否把这种风险从受控数据迁移到真实观测？** 间隙/模糊宽度、像素短边、对比度和方向只是假设中的解释变量；数字退化的高斯 sigma 不等于真实成像系统的总 PSF，也不能把条件检测边界称为物理分辨极限。

现有四级退化同时改变模糊和采样，不能分离两者作用；自然相邻与孤立目标之间也可能保留未测量混杂。因此，首验只能支持指定协议下的条件额外风险。若首验通过，后续机制实验应分别改变模糊与采样，使用小规模正交组合和预先定义的自然间隙分层，先检验短边、对比度之外的增量预测价值；不能从四个共变等级拟合出所谓普适分辨定律。

### 从有效首验到论文的条件路线

1. **先得到可信性能信号。** 继续使用 HRSC2016、既有 100 组、同一四级退化和两类冻结检测器；先完成 clear 与最严重等级的匹配对照结果，随后补齐中间等级、原定分数/NMS 敏感性和真正 NMS 前证据。不新增检测器训练或复杂生成器。首验成功只获得继续研究资格，不等于顶刊证据。
2. **核心现象成立后，先验证迁移与真实桥接。** 使用一个更密集且有可复用基线的独立遥感集（SODA-A 或 DOTA，按数据与权重条件择一），按原图/场景划分，先冻结分析再计算；最终应加入一个未参与拟合、不同检测范式的观察者以检验模型特异性。这里是后续路线，不是当前任务扩展。真实配对优先对 [DSR](https://github.com/IVRL/DSR) 取得样本后核查静态实例、独立 HR 数量标注、配准残差和重复场景，不能只复读网页。公开数据没有检测标签不等于永远不合格，可以独立标注补足；仍未核验的项目必须保持未知。RRSISR 的 DOI 元数据已复核为《Toward Real-World Remote Sensing Image Super-Resolution: A New Benchmark and an Efficient Model》，本次未取得新样本级证据，不提升其资格。
3. **真实桥接合格后再决定是否需要方法。** 固定“普通模糊/采样”“传统复合退化”“有足够元数据时的 pyBSM”等对照；在同一校准场景和参数预算下分别按图像质量、单目标行为、相邻组事件分布校准。只允许成像参数改变，不允许生成/移除实例。首先检验前两种匹配能否预测真实邻接风险；若已经足够，则不开发额外模型。只有存在稳定缺口，才研究低维、受成像约束的实例行为校准。
4. **论文级证据必须落在未见数据。** 校准、验证、测试按独立场景分开，同景裁块/不同高度/低高清配对必须在同一分区。主要比较是真实 held-out 场景上的完整分解率预测误差、基数 MAE、merge/duplicate/miss 概率误差及校准误差，而非只比较 mAP。报告相对于最佳简单对照的效应与场景簇置信区间；用独立场景数量做样本量设计，不能把大量邻近裁块当独立样本。若只在拟合用检测器或模拟条件有效，不作跨观察者或真实世界忠实性主张。

若有效首验仍主要是普通 miss、原继续条件不成立，停止当前“独特实例分解错误→任务忠实退化模型”路线；这是研究投入决策，不是统计上接受零假设。若效应方向正但区间很宽，报告精度不足，不能写成不存在效应；是否另做精度研究需由这些结果决定，不能靠换数据、调门槛或换方法名称延续原主张。
