# P12：相邻遥感目标的退化可分辨性

类型：`RESEARCH`

本项目研究：相邻遥感目标在受控成像退化下何时不再能被检测器稳定分解，以及错误表现为 merge、split 还是 miss。图像退化生成是制造受控观测条件的工具，不是当前主问题。

当前结论边界：没有同景真实低/高清观测与独立目标真值时，只能报告受控合成条件下的检测器行为，不能声称模拟器具有真实世界忠实性。只有先证明普通图像质量指标或单目标表现掩盖了稳定的相邻实例错误，并获得合格真实观测桥接，才考虑开发任务忠实的退化模型。
